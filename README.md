# 今夕 · 隐私政策公开页

Public privacy page for 今夕 (Jinxi), an offline "sense of time" app
(月相 / 节气 / 黄历 / 诗词), hosted via GitHub Pages for app-store review.

- `index.html` — 隐私政策 (privacy policy)

## 启用 GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** →
Branch: **main** / **/(root)** → Save.

发布后地址：

- 隐私政策：`https://andrewwang8366.github.io/jinxi_public/`

内容与 App 内《设置 - 隐私政策》展示的文本保持一致。
